# AGENTS.md

Entry point for anyone — person or tool — working on this repository without
prior context. This file routes; it does not restate. Follow the link.

MediaStack is a turnkey single-box media server: one guided setup, no config
editing, safe re-runs. Bash and stdlib Python only, orchestrating Docker
Compose. Every design choice serves zero-friction setup and low maintenance.

## Before you claim you are done

```
./tests/check.sh fast     # image-free: shellcheck, shfmt, ruff, mypy, secrets
./tests/check.sh          # default tier — the local equivalent of the CI gate
```

Both are described, with their single-stage selectors, in the usage header of
[tests/check.sh](tests/check.sh) itself. Run the narrowest thing that covers
your change, then the default tier before you open a pull request.

## Standing rules

- Code and compose files are authoritative. When a document disagrees with the
  tree, fix the document.
- Three files control the product: `docker-compose.yml` (how services run),
  `config.yml` (what gets configured), `.env` (secrets and host-specific
  values, generated by `setup.sh`). Configuration belongs in `config.yml`, not
  in bash.
- Setup is optimised for first run and must stay safe to re-run: skip what is
  already configured, warn on drift, never auto-reconcile.
- Do not commit `.env`, live service config under `config/<service>/`, or
  generated host artifacts. A publication guard enforces this — see the
  enforcement table in [docs/conventions.md](docs/conventions.md).
